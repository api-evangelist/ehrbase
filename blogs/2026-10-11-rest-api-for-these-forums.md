Possibly of interest for users that are using REST APIs to access Discourse openEHR Discourse MCP Setup Guides General Discussion DIscourse now has a built-in web-facing MCP server. The distinction between the web MCP and the locally-running MCP which most of this thread discusses is that the new Discourse MCP is an interface exposed by the DIscourse server itself, it’s not a service you need to run in npx locally. This makes it easier to connect to more ‘commodity’ and less technical AI tools like Claude Web or ChatGPT web.
